# 形函数与等参单元

弱形式把问题化为对基函数 $N_i$ 的积分。有限元方法的做法是：把求解域剖分为若干**单元**，在每个单元上用局部定义的**形函数**插值场变量，最后拼回全局。

## 参考单元与等参映射

为复用代码，所有单元先在**参考单元**（参数空间）上定义形函数，再通过一个坐标映射把参考单元"搬到"物理空间。设参考坐标为 $ξ$，物理坐标为 `x`，映射为

$$
x(\xi) = \sum_{a=1}^{N} N_a(\xi)\, x_a
$$

其中 $x_a$ 是单元第 `a` 个节点的物理坐标。若场变量用同一组形函数插值：

$$
u(\xi) = \sum_{a=1}^{N} N_a(\xi)\, u_a
$$

则称为**等参单元**（几何与场共用同一套形函数）。`rustfem` 的 `Element::coordinates` 实现的正是等参映射。

## 形函数的两条基本性质

形函数在节点处满足 **Kronecker δ** 性质：

$$
N_a(\xi_b) = \delta_{ab} = \begin{cases} 1, & a = b \\ 0, & a \ne b \end{cases}
$$

并满足**单位分解**：

$$
\sum_{a=1}^{N} N_a(\xi) = 1
$$

前者保证 $u(\xi_b) = u_b$（节点值恰好是系数），后者保证刚体平移（常数场）能被精确表示。

## 1D：`Seg2` 的形函数

参考区间为 `[-1, 1]`，两端点 $ξ = -1$、$ξ = +1$ 对应节点 1、2。线性（拉格朗日）插值为

$$
N_1(\xi) = \frac{1-\xi}{2}, \qquad N_2(\xi) = \frac{1+\xi}{2}
$$

这正是 `Seg2` 中 `shape` 的实现：

```rust
fn shape(&self, ξ: [f64; 1]) -> [f64; 2] {
    let ξ = ξ[0];
    [0.5 * (1.0 - ξ), 0.5 * (1.0 + ξ)]
}
```

验证：$N_1(-1) = 1$、$N_2(-1) = 0$；$N_1(1) = 0$、$N_2(1) = 1$；$N_1 + N_2 = 1$。

## 2D：`Tri3` 的面积坐标

参考三角形顶点为 `(0,0)`、`(1,0)`、`(0,1)`（参数坐标 $(ξ, η)$）。形函数

$$
N_1 = 1 - \xi - \eta, \qquad N_2 = \xi, \qquad N_3 = \eta
$$

这三个函数恰是三角形内一点到各边"相对面积"的比例（面积坐标），自动满足单位分解与 Kronecker δ。

## 2D：`Quad4` 的双线性形函数

参考四边形为 $[-1, 1]^2$。形函数是一维线性函数的张量积：

$$
N_a(\xi, \eta) = \frac{1}{4}(1 + \xi_a \xi)(1 + \eta_a \eta), \quad a = 1,2,3,4
$$

其中 $(\xi_a, \eta_a)$ 是第 `a` 个节点的参考坐标。展开即 `usage-elements` 章所列的四项。

## 0D：`Poi1` 的形函数

点单元的参数空间是 0 维，形函数恒为 1：

$$
N_1 = 1
$$

它不插值任何场，只用于"定位"——把约束或集中力施加到某个具体节点。

## 形函数的导数

弱形式里出现的是 `dN/dx`（物理导数），而形函数是参数坐标 $ξ$ 的函数，两者通过**链式法则 + 雅可比**联系，这正是下一章的内容。`rustfem` 中：

- 1D 单元 `Seg2::derivative_shape` 直接返回物理导数 `dN/dx`；
- 2D 单元 `Tri3`/`Quad4` 的 `derivative_shape` 只返回 $∂N/∂ξ$，完整梯度需结合雅可比矩阵另行计算。
